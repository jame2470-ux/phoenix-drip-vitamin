# DRIP VITAMIN — Card Link (10 October 2026)

ไฟล์ชุดนี้ทำเป็น Card Link ใหม่ เพื่อไม่ทับและไม่ติดแคชของคลาสรอบเก่า

## วิธีอัปโหลด

1. สร้าง GitHub repository แบบ **Public** ชื่อ `drip-vitamin-card-link-oct-2026`
2. อัปโหลดไฟล์ 3 ไฟล์นี้ไว้ที่หน้าแรก (root) ของ repository
   - `index.html`
   - `drip-vitamin-cover.jpg`
   - `README.md`
3. ไปที่ **Settings → Pages** เลือก Deploy from a branch: `main` / `root` แล้วกด Save
4. รอ GitHub Pages ทำงาน แล้วใช้ลิงก์นี้ส่งใน LINE:

   `https://jame2470-ux.github.io/drip-vitamin-card-link-oct-2026/`

ลิงก์นี้จะแสดงการ์ด DRIP VITAMIN และเมื่อกดจะพาไป Google Site ของคลาสโดยอัตโนมัติ

> สำคัญ: ชื่อ repository ต้องตรงตามข้อ 1 เพื่อให้ลิงก์และภาพการ์ดทำงานถูกต้อง
